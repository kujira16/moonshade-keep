# Codex への追加指示：主人公 32×32 に「目」と「肩当て」をはっきり描く

対象は**主人公の5種類だけ**（`player_idle` `player_walk` `player_jump` `player_attack` `player_attack_air`、合計9コマ）。
前回（`docs/CODEX_KNIGHT_CLEANUP.md`）でザラつきは取れたが、平らに塗ったぶん、目と肩当てが見えなくなった。
**gpt-image で作り直す必要はない。** 今の `assets/source/` の絵に、決まった形の部品を上から描き足す処理（スタンプ）を追加する。

## 今の絵の問題（`assets/source/player_idle.png`、座標は (列, 行)、0 始まり）

- **目**：(22〜23, 12〜14) に 2×3 の暗い点があるが、顔の右端の輪郭 (25 列) とほぼくっついていて、輪郭の一部に見える。
- **顔と体の境目がない**：顔（色 2）と鎧（色 2）が同じ色で、あごの下から胴体までつながって見える。
- **肩当て**：丸い形がなく、胴体の色 2 に埋もれている。
- **髪**：4〜9 行目が一番明るい色の大きな塊で、髪の毛らしい筋がない。

## 追加するもの（立ち絵の座標。他のコマは同じ部品を位置だけずらして描く）

1. **目（いちばん大事）**
   - 一番暗い色の 2×3 を **(20〜21, 12〜14)** に置く。左上 (20, 12) だけ一番明るい色（白いハイライト）。
   - 目の右側 (22〜23, 12〜14) は顔の色 2 で埋め、**目と輪郭の間に肌を 2 列あける**。
   - 今ある (22〜23, 12〜14) の暗い点は消す。
2. **あごの線（顔と体を分ける）**
   - 顔の下端の 1 行下（立ち絵では 17 行目）の、顔の幅（16〜23 列）を一番暗い色の線にする。
3. **肩当て**
   - 手前の肩（立ち絵では中心 (19, 20) あたり）に、**直径 6 の円**を描く：外周 1px は一番暗い色、その内側の上半分の縁 1px は一番明るい色、中は色 2。
   - 奥の肩（中心 (6, 20) あたり）は、同じ円の右半分だけ（手前の体に隠れる）。
4. **前髪の筋**
   - 髪の塊の中に、色 2 の筋を 3 本、斜め（右下がり）に入れる。長さ 4〜5 px、筋どうしの間は 3 px 以上あける。
   - 前髪の下端（目の上、11 行目）を色 2 の影にして、髪と顔の境目をはっきりさせる。

## 実装

- `tools/knight_details.py` を新しく作り、上の 4 つの部品を描く関数にする。描く位置は **コマごとに `tools/sprite_prompts.json` の `"details"` に書く**（例：`"eye": [20, 12]`, `"chin": [16, 23, 17]`, `"pauldron": [19, 20]`, `"pauldron_back": [6, 20]`）。9 コマ分の座標は、各コマの絵を見て決める。
- 攻撃コマは体が前に傾いているので、座標を合わせること。剣を持つ腕と肩当てが重なる場合は、肩当てを優先する。
- 歩き4コマは今まで通り立ち絵の頭をそろえる（そろえる範囲を 0〜17 行目に広げる）。
- 流れは `assets/source/<名前>.png`（今の絵）→ `knight_details.py` → `polish_sprites.py` → `assets/<名前>.png`。`gen_sprites.py --reprocess` でもこの順に通るようにする。
- `tools/hires_parts.py` の `has_knight_details` を、新しい目（2×3 の暗い点＋ハイライト 1、右に肌 2 列）・あごの線・肩当ての円をチェックする内容に更新する。
